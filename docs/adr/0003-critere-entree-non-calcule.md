# Critère d'entrée ACR/EULAR non calculé

Les critères ACR/EULAR 2016 ne s'appliquent qu'aux patients ayant un symptôme de sécheresse ou une suspicion sur un domaine ESSDAI, information présente seulement dans le texte libre. On ne le calcule pas : toute combinaison d'Items ACR/EULAR atteignant 4 points contient une biopsie ou un Test de sécheresse (l'Anti-SSA seul vaut 3), ce qui suppose déjà une suspicion clinique. Un proxy « exploration glandulaire documentée » serait donc toujours vrai, et une extraction des symptômes élargirait le périmètre NLP sans changer le résultat attendu.
